# 微信计划插件热重载修复设计

## 目标

让运行中的 OpenClaw 微信网关加载当前工作区的计划插件，使“删除8月9日睡觉时间”执行删除而非查询。

## 已确认事实

- 微信插件的 `fast-routine.js` 直接导入 `D:/BaiduSyncdisk/Study/AI/codex/codex-study/plan/core/index.mjs`。
- 工作区路由已包含 `handleExplicitSleepCommand`，且回归测试已通过。
- 因 Node 网关进程仍在运行，它保留了修改前的模块缓存。

## 方案

不复制插件文件、不修改 SQLite 数据。使用 OpenClaw 的网关重启入口重启当前网关进程，再检查新进程和日志中的插件加载记录；最后通过本地同一入口验证删除命令返回删除结果。

## 验收

- 重启后网关进程恢复运行。
- 本地插件入口对“删除8月9日睡觉时间”返回“删除指定日期睡觉时间”，且不会把它作为查询处理。
- 不对正式睡眠记录进行试删；只使用临时 SQLite 验证路由与数据库行为。
