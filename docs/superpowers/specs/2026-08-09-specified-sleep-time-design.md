# 指定日期睡觉时间补录

## 目标

在计划插件中支持按指定作息日期新增、修改和删除睡觉时间，并写入既有 `sleep_events` 表。

## 日期语义

用户写出的日期始终是记录的 `routine_date`（作息归属日期）。时间为 00:00 至 05:59 时，保存的实际入睡时刻 `slept_at` 落在次日；06:00 至 23:59 则落在当天。

例如：

- `8月3日睡觉时间 2:04`：`routine_date=2026-08-03`，`slept_at=2026-08-04T02:04:00+08:00`。
- `8月3日睡觉时间 23:40`：`routine_date=2026-08-03`，`slept_at=2026-08-03T23:40:00+08:00`。

现有精确指令 `已睡觉` 保持原有 06:00 自动归属逻辑，不受影响。

## 用户指令

- `8月3日睡觉时间 2:04`：新增记录；同一 `routine_date` 已有记录时覆盖。
- `修改8月3日睡觉时间为 2:04`：更新该日期记录；不存在时返回未找到提示。
- `删除8月9日睡觉时间`：删除该日期记录；不存在时返回未找到提示。

成功回复必须同时显示归属日期和实际入睡时刻，凌晨示例明确显示为次日。

## 实现边界

- 路由层解析新增、修改和删除指令，复用 Asia/Shanghai 日期解析。
- Python CLI 新增按显式作息日期保存、更新和删除的数据库操作；不迁移表结构。
- 查询、统计和图表继续读取 `sleep_events`，无需修改数据格式。
- 更新插件帮助和 README。

## 验证

- 测试 02:04 跨日保存、23:40 当日保存及响应文案。
- 测试新增覆盖、显式修改、删除和删除不存在记录。
- 回归验证 `已睡觉` 仍按既有 06:00 边界归属。
