# Plan 时段标题过滤设计

## 目标

微信机器人接收从 Plan 复制的每日计划时，忽略仅用于视觉分组的时段标题。标题不进入计划原文、结构化项目或后续提醒。

## 识别规则

仅过滤去除首尾空白后完全等于下列文字的独立行：

- 凌晨
- 早上
- 上午
- 中午
- 下午
- 傍晚
- 晚上
- 夜间
- 夜里

过滤只在计划保存入口生效。计划查询、每日记录、起床和通用提醒的时间表达不受影响。

带时间范围的计划项不得进行关键词删除。例如 `18:00-18:50 下午复盘` 的任务名称仍为 `下午复盘`。包含更多文字的独立行也不删除，避免误伤真实任务。

## 数据流

1. 机器人收到包含计划的微信文本。
2. 计划路由在日期识别和项目解析前生成清洗后的计划文本。
3. 清洗后的文本用于计划识别、项目解析和 `rawText` 持久化。
4. 后续提醒继续只读取结构化计划项目，因此不会出现被过滤的分组标题。
5. 用户已经发到微信里的原消息不会被修改；过滤从机器人接收消息后开始。

## 兼容与错误处理

- 空行和现有项目格式继续按原逻辑处理。
- 清洗后没有有效计划项目时，仍按现有规则判定为非计划或返回现有保存错误，不创建空计划。
- `今日计划`、`明日计划`等计划标题不是时段标题，必须保留。
- 保存、查询和提醒的回复格式保持不变。

## 验证

自动测试覆盖：

1. 示例文本中的独立 `下午`、`晚上` 不出现在保存的 `rawText`、结构化项目和提醒标题中。
2. `上午`、`中午`、`傍晚`、`夜间`等同类独立标题同样被过滤。
3. `18:00-18:50 下午复盘`保留完整任务名称。
4. `今日计划`标题、计划日期和所有时间范围保持不变。
5. 现有计划保存、查询及提醒测试继续通过。
