# 移除指定日期睡觉指令设计

## 目标

删除指定日期的睡觉时间添加、修改和删除聊天入口；保留现有“已睡觉”和睡眠统计查询。

## 行为

- `8月3日睡觉时间 2:04`、`修改8月3日睡觉时间为 2:04`、`删除8月3日睡觉时间` 不再由本地计划插件处理，也不得误识别为睡眠查询。
- 移除只为这些聊天命令服务的 CLI 参数、数据库方法、帮助说明和测试。
- 直接写入两条用户指定的正式记录：归属日 `2026-08-06` 的实际时刻 `2026-08-07T05:00:00+08:00`；归属日 `2026-08-07` 的实际时刻 `2026-08-08T07:00:00+08:00`。

## 验收

- 所有项目测试通过。
- 网关重启后不再保留旧模块缓存。
- 数据库仅包含以上两条对应归属日的目标值。
