# 状态图片采集超时修复设计

## 原因

状态命令使用 20 秒同步 PowerShell 超时，而当前完整采集实测约 21.7 秒。完整采集在状态图中也会执行硬件枚举，导致日常状态请求不必要地超时。

## 设计

- PowerShell 采集器接受 `status` 和 `hardware` 两种模式。
- `status` 仅采集状态图需要的运行、CPU、内存、磁盘、进程、网络和温度数据，不执行硬件 CIM 枚举。
- `hardware` 执行完整硬件枚举，超时上限为 45 秒。
- `status` 超时上限为 30 秒；若仍超时，返回“状态采集超过 N 秒”的可读错误。
- 状态与硬件命令都将模式传给自定义采集器，方便测试。

## 验收

- 状态和硬件图片均能在当前电脑成功生成。
- 不再向用户展示 `spawnSync pwsh.exe ETIMEDOUT`。
- 插件测试和渲染测试通过，网关重启后健康检查正常。
