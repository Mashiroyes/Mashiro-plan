# 财报任务低频调度与隐藏启动设计

## 目标

财报任务每天只在 12:30 和 18:30 触发，点评任务每 30 分钟检查一次，三个计划任务均由隐藏 VBS 启动 PowerShell 7。

## 行为

- 两个财报触发点共享同一天的 SQLite 幂等记录，因此最多发送一份；18:30 只在中午漏发时补发。
- 点评任务没有待处理答案时只检查数据库，不调用 OpenClaw。
- 招股书仍在周二、周五 18:10 触发一次。
- 计划任务启动 wscript.exe，通用 run-worker.vbs 用 Shell.Run(command, 0, True) 隐藏并等待 PowerShell worker。

## 验证

- Windows 边界测试检查 VBS 隐藏执行与参数约束。
- 隔离安装测试检查 wscript 入口、12:30 和 18:30 触发器、30 分钟点评间隔。
- 正式任务核对运行副本哈希、SQLite 完整性、动作和下次运行时间。
