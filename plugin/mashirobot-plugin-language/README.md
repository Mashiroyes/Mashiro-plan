# 语言学习插件

英语统计和关键词管理由本插件提供；计划插件只保存计划时段，两个插件共用 `plan\sqlite\openclaw-planner.sqlite`。

## 指令

- `本周英语统计图`、`7月英语学习统计图`、`2025年英语学习`、`昨天英语学习统计`
- 时间前缀支持今天、昨天、周、月、年和具体日期；无前缀时默认本周
- 后缀支持“英语学习统计图”“英语学习”“英语统计图”“英语学习统计”
- 手动查询的文字回复只显示间隔提醒，四项时长显示在图片中
- `本月目标时长：3h`：设置本月每日目标；也支持“目标每天时长”和“小时/分钟”写法
- `如果今天学习8h`、`如果明天学习8h`、`如果昨天学习3h`
- `如果未来7天每天学习8h`、`如果接下来30天平均每天学习6.5h`
- `如果今天不学习呢`：按今天最终为 0 分钟模拟
- `英语关键词`：查看听说读写的内置和新增关键词
- `英语关键词增加 阅读 上古卷轴5wiki`
- `英语关键词删除 阅读 上古卷轴5wiki`

关键词修改会立即重新识别现有计划。内置关键词受保护；删除指令只会删除此前通过指令新增的关键词。

## 学习时长假设模拟

模拟固定基于本月截至今天的真实四项学习记录和本月每日目标，不会写入计划、每日记录或目标，也不会影响下一次模拟。单日的“今天/昨天学习 N 小时”表示将该日最终总学习时长替换为 N 小时；“明天”与未来多日假设则新增统计天数。回复只展示平均时长、总时长、统计天数和与目标的差值，不附加学习建议。
